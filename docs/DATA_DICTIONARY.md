# Data Dictionary & Schema Specification

**Project Title:** AI-Powered Research Paper Semantic Search & Retrieval System  
**Database:** PostgreSQL 17 + `pgvector`  
**Embedding Model:** `Xenova/all-MiniLM-L6-v2` (384-dimensional dense vectors)

---

## 1. Table: `users`
Represents system actors with Role-Based Access Control (RBAC).

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `user_id` | `SERIAL` | `PRIMARY KEY` | Unique identifier for user |
| `email` | `VARCHAR(255)` | `UNIQUE, NOT NULL` | Login email address |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` | Hashed credential (bcrypt) |
| `full_name` | `VARCHAR(150)` | `NOT NULL` | Display name of user |
| `role` | `VARCHAR(50)` | `NOT NULL, CHECK (role IN ('ADMIN', 'RESEARCHER'))` | RBAC role |
| `created_at` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Account creation timestamp |
| `updated_at` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Last updated timestamp (via trigger) |

---

## 2. Table: `research_paper`
Stores research paper metadata and text content.

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `paper_id` | `SERIAL` | `PRIMARY KEY` | Unique paper identifier |
| `title` | `VARCHAR(500)` | `NOT NULL` | Title of paper |
| `abstract` | `TEXT` | `NOT NULL, CHECK (length >= 20)` | Paper abstract (source of vector embeddings) |
| `authors` | `VARCHAR(300)` | Nullable | Authors list |
| `category` | `VARCHAR(100)` | Nullable | Research field/category |
| `publication_date`| `DATE` | Nullable | Original publication date |
| `upload_date` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Upload timestamp |
| `user_id` | `INT` | `REFERENCES users(user_id) ON DELETE SET NULL` | Uploader FK |
| `updated_at` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Modification timestamp (via trigger) |

---

## 3. Table: `vector_embedding`
Stores dense vector representations generated by sentence-transformer models.

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `embedding_id` | `SERIAL` | `PRIMARY KEY` | Unique embedding identifier |
| `paper_id` | `INT` | `UNIQUE, NOT NULL, REFERENCES research_paper(paper_id) ON DELETE CASCADE` | 1:1 foreign key to paper |
| `model_version` | `VARCHAR(100)` | `NOT NULL, DEFAULT 'all-MiniLM-L6-v2'` | Name of transformer model |
| `vector_data` | `vector(384)` | `NOT NULL` | 384-dimensional dense vector |
| `created_at` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Generation timestamp |

**Index:** `idx_vector_embedding_hnsw` using HNSW with `vector_cosine_ops`.

---

## 4. Table: `search_query`
Logs queries executed by users for auditing and retrieval analytics.

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `query_id` | `SERIAL` | `PRIMARY KEY` | Unique query log identifier |
| `query_text` | `TEXT` | `NOT NULL` | Search text entered by user |
| `timestamp` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Query execution time |
| `user_id` | `INT` | `REFERENCES users(user_id) ON DELETE SET NULL` | Executing user FK |

---

## 5. Table: `query_retrieval` (Associative Table)
M:N relationship tracking which papers were retrieved for each query, with similarity score and ranking.

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `query_id` | `INT` | `REFERENCES search_query(query_id) ON DELETE CASCADE` | Composite PK component |
| `paper_id` | `INT` | `REFERENCES research_paper(paper_id) ON DELETE CASCADE` | Composite PK component |
| `similarity_score`| `DOUBLE PRECISION`| `NOT NULL, CHECK (similarity_score BETWEEN -1.0 AND 1.0)` | Cosine similarity value |
| `rank_order` | `INT` | `NOT NULL, CHECK (rank_order > 0)` | Retrieval rank (1, 2, 3...) |
| `retrieved_at` | `TIMESTAMPTZ` | `DEFAULT CURRENT_TIMESTAMP` | Record timestamp |

**Primary Key:** `(query_id, paper_id)`

---

## 6. Table: `paper_audit_log` (Trigger Table)
Populated automatically by trigger `trg_audit_paper_changes` whenever papers are modified or deleted.

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `audit_id` | `SERIAL PRIMARY KEY` | Audit entry ID |
| `paper_id` | `INT` | Target paper ID |
| `action_type` | `VARCHAR(10)` | 'UPDATE' or 'DELETE' |
| `old_title` | `VARCHAR(500)` | Previous title |
| `new_title` | `VARCHAR(500)` | Updated title (NULL on delete) |
| `changed_by_user_id` | `INT` | User initiating modification |
| `changed_at` | `TIMESTAMPTZ` | Timestamp of event |
